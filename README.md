# BridgeWatch AI

UMBC DATA 606 Capstone — predicting whether a bridge's condition will deteriorate by its next inspection,
using FHWA National Bridge Inventory data (2020–2025, 7 states).

- [Project proposal](docs/proposal.md)
- [Exploratory data analysis](notebooks/eda.ipynb)
- [Author resume](docs/Resume.md)

## Repository structure

- `data/` — raw NBI files and the processed model-ready dataset
- `notebooks/` — exploratory analysis and (later) model training notebooks
- `app/` — Streamlit application
- `docs/` — proposal, report, and resume
