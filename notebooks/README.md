# Notebooks

- **`eda.ipynb`** — Exploratory data analysis for the BridgeWatch AI capstone project. Validates schema
  consistency across all 42 raw NBI files, checks data quality (duplicates, missing values, malformed
  coordinate fields), explores feature and target distributions, and builds the model-ready dataset
  (`../data/processed/bridge_deterioration_dataset.csv.gz`) used for training.
